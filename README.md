# 電子くんとジュール熱

電子くんの動きと、障害物に出会ったときの光で、ジュール熱の発生をイメージするHTMLアニメーション教材です。

**教材を開く → https://itibanbosi.github.io/joule-heat-simulator/**

## 操作方法

- **障害物の多さ（抵抗）**を変えると、下側の抵抗値を1〜8 Ωの範囲で変えられます。
- **電流の設定**では、1〜5 Aを0.5 A刻みで選べます。上下を同じ電流の条件で比較します。
- **一時停止／再生**でアニメーションを止めたり再開したりできます。
- **最初から**で電子くんの位置と熱のアニメーションをリセットします。抵抗・電流の設定値は保持されます。

上側は抵抗1 Ω、下側は選んだ抵抗値です。下側では障害物をよけるジグザグの動きや、一時停止、周囲が赤く光る様子で、進みにくさとエネルギーの移動を表します。

## 比べてみよう

1. 電流を同じにして、下側の抵抗を大きくします。表示される発熱の電力が抵抗に比例して増えます。
2. 抵抗を同じにして、電流を2倍にします。発熱の電力は4倍になります。
3. 下側を1 Ωにし、上下の発熱の電力が同じになることを確かめます。

## 式と表示

**P = I² × R**

- Pは発熱の電力（W）です。
- Iは電流（A）、Rは抵抗（Ω）です。
- 初期設定は2.0 Aです。上側1 Ωは4.0 W、下側5 Ωは20.0 Wになります。
- 一定時間t秒の熱量は **Q = I²Rt（J）** です。この教材の数値表示は電力Wです。

## 模型の読み方

実際の金属では、電子が原子の振動や不純物などで散乱され、電気的エネルギーが物質に伝わります。

上下は**電流が同じ条件**の比較です。下側の減速・寄り道・停止は進みにくさを表すたとえで、実際の電子の移動速度や衝突回数を定量的に示すものではありません。光の頻度や画面上の衝突回数は測定値ではありません。
